# AgriVision-Crop — Synthetic Crop Suitability Classification

Maps generated nutrient and climate profiles to one of six labels (rice, wheat, maize, cotton, banana, coffee). The class profiles are hand-specified for an offline coding demonstration.

Synthetic data only. This is not agronomic advice. The profile distributions are illustrative, omit local soil, cultivar, management, and measurement variation, and must not guide planting decisions.

Run: `python -m agrivision.train --json`; tests: `python -m pytest -q`.
